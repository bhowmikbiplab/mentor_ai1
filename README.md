# 🤖 MentorAI

### AI-Powered Project Recommendation & Mentorship Platform

🔗 **Live Demo:** https://mentor-ai-hazel.vercel.app

> **Visit MentorAI →** https://mentor-ai-hazel.vercel.app

MentorAI is a modern web application designed to help students discover suitable software projects based on their **interests, skill level, and technology preferences**.

Instead of randomly selecting a project, MentorAI guides students through a structured assessment and provides a personalized project recommendation along with a detailed roadmap, required technologies, features, architecture, challenges, and development guidance.

## 🎯 Project Objective

MentorAI aims to solve a common problem faced by students: **choosing the right project to build**.

It helps students understand:

* What project they should build
* Which project matches their skills
* Which technologies they can use
* What features they should implement
* How to structure the project
* What challenges they may face
* How to proceed step-by-step
